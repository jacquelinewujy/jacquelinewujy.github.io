Smart Chessboard

Class Project · Vibe Coding · Embedded Systems · 3D Printing

Smart Chessboard combines a physical chessboard with real-time move guidance, developed in my entrepreneurship prototyping class.

Role
Designer & Developer
Timeline
March 2026- April 2026

How It Works

The board detects piece positions and communicates recommended moves through LEDs embedded beneath the playing surface.

Technical Build

Sensing
Reed switches + magnetic chess pieces
Interpretation
ESP32 captures sensor states; software developed with Claude Code translates them into a chess position
